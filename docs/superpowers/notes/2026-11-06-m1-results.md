## 2. 实现清单

### Electron 主进程
- `paths.ts`：Windows 沿用 `%LOCALAPPDATA%\chatnip`，macOS/Linux 用 `userData`；旧数据迁移；目录布局。
- `server/`：Hono + `@hono/node-server`，`127.0.0.1:0`；token/Host/Origin/CORS/32MB 限制；app-state、files、napcat、opencode 路由。
- `protocol.ts`：`app://chatnip` 静态服务 + SPA fallback + CSP。
- `security.ts`：sandbox/contextIsolation、导航/权限拒绝、CSP 响应头。
- `services/opencode/`：manifest（v1.19.5 六平台 SHA-256）、下载/续传/校验/解压、serve 生命周期、健康检查、重启、日志。
- `services/qq/`：NapCat 检测、配置、safeStorage、健康检查、启动器、WebUI、引导安装。
- `ipc.ts` + `preload`：窄接口暴露 apiBase/token/服务状态/操作。
- 自动更新：`electron-updater`（打包后检查）。

### Renderer
- `src/api/runtime.ts`：apiBase/token/apiFetch。
- NapCat/Opencode/appState/fileWriter/SettingsPage 全部切换。
- `src/lib/historyPager.ts`：去重、四重停止条件（覆盖/空/短批/锚点停滞/上限）。
- `src/lib/dateGroups.ts`：本地日期分组。
- `src/store/bootstrap.ts`：app-state 启动恢复 + localStorage 合并。
- 会话列表：远端会话不再被注册表过滤掉；未知会话降级为普通对话。
- `SetupPage` + `ServiceStatusCard` + `ErrorBoundary`；首启跳转。

### 打包 / CI / 文档
- `electron-builder.yml`：NSIS/DMG+zip/AppImage+deb、entitlements、fuses、GitHub publish。
- `.github/workflows/release.yml`：三平台矩阵、draft release。
- CI quality 增加 `typecheck:node` 与 `build:electron`。
- README 重写为桌面版；设计/计划/决策记录同步。

## 3. 已知缺口

1. **app.asar 已从 261MB 裁剪到 7.6MB**：renderer-only 依赖移到 devDependencies，仅保留主进程运行时依赖（hono/@hono/node-server/adm-zip/tar/electron-updater）。安装包体积现在主要由 Electron 本体决定。
2. **图标**：尚未提供 `build/icon.ico` / `icon.icns` / 512px PNG。
3. **E2E**：未编写/运行 Playwright Electron 用例（按用户要求减少实际测试）。
4. **签名/公证**：配置已留好条件分支，证书需外部采购；无签名时需文档引导手动放行。
5. **NapCat 真实联调**：登录、WebUI 端口探测、深翻页（>5000 条短 ID 缓存淘汰）需在真实环境验证。
6. **离线安装包**：默认不启用；可作为后续可选产物。
7. **自动更新**：已接入检查，但未在已安装版本上做升级验证。
8. **Opencode 手动路径回退**：下载失败时的“选择本地二进制”尚未做 UI；当前会进入 error 状态并可重试。
