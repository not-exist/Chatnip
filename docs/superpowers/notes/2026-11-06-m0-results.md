## 2. 关键发现

1. **必须用 `app://` 加载生产 renderer**：`loadFile` 下 `file://` 无法解析绝对 `/assets`，BrowserRouter 也无 SPA fallback；M1 Task 8 解决。
2. **electron-vite 默认不压缩 renderer**：不设 `build.minify` 时产物 2.07 MB；显式 `minify: 'esbuild'` 后 849 kB（与 Web 构建一致）。
3. **ESLint 必须忽略 `out/`、`release/`**：否则会把打包产物当源码 lint，产生 1600+ 误报。
4. **app.asar 目前 256 MB**：electron-builder 把生产 `node_modules` 全量打入；M6 需要只保留主进程运行时依赖（renderer 已 bundle），并排除 React/HeroUI 等仅 renderer 依赖。
5. **Opencode 1.19.5 行为已实测**：`serve --hostname 127.0.0.1 --port <port>` + `OPENCODE_SERVER_PASSWORD` + Basic Auth；`/global/health` 返回版本；`/event` 是 SSE，代理必须流式转发。
6. **NapCat**：Windows/Linux/macOS 12+ 官方支持；安装器依赖 QQ/GUI/管理员权限 → 采用引导安装；非商业 Limited Redistribution License → 不内置打包；`message_seq` 传上一批最旧 `message_id` 是兼容用法。
